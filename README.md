## Overview
This repository contains C++ implementations for doubly linked lists, circular linked lists, array-based stacks, and linked-list-based stacks.

## File Map
- `Q1.cpp`: Doubly Linked List - Append, Forward/Reverse Traversal, Memory Deallocation.
- `Q2.cpp`: Doubly Linked List - Positional Insertion (`InsertBefore`) and Node Deletion.
- `Q3.cpp`: Circular Linked List - Append, Cycle Traversal, Node Count, and Unlinking Cleanup.
- `Q4.cpp`: Circular Linked List - Node Deletion handling Head, Tail, Single-Node, and Duplicate cases.
- `Q5.cpp`: Array-Based Stack - Fixed Capacity (5 elements) with Overflow/Underflow checks.
- `Q6.cpp`: Linked-List Stack - Dynamic $O(1)$ Stack Operations with Interactive Menu and Full Cleanup.
